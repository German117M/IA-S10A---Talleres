# Proyecto de Inteligencia Artificial

## Descripción

Este repositorio corresponde a un proyecto académico desarrollado **semana a semana** en la asignatura de **Inteligencia Artificial** del programa de Ingeniería de Sistemas.

Cada semana se incorporan nuevas prácticas, ejercicios y conceptos relacionados con diferentes áreas de la inteligencia artificial, manteniendo un repositorio acumulativo con el código, datos, reportes y resultados obtenidos.

## Tecnologías utilizadas

* Python 3
* scikit-learn
* NumPy
* Pandas
* Matplotlib
* JupyterLab
* Git
* GitHub
* Visual Studio Code

## Trabajo realizado

Hasta el momento se han desarrollado prácticas relacionadas con:

* Fundamentos de aprendizaje automático.
* Uso del conjunto de datos Iris.
* Regresión logística.
* Estandarización de datos.
* División de datos en entrenamiento y prueba.
* Evaluación mediante accuracy y matriz de confusión.
* Taxonomía y categorías de inteligencia artificial.
* Clasificación simbólica mediante reglas y palabras clave.
* Generación automática de reportes.
